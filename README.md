# Проект Analysis_of_bank_transactions
Учебный проект "Приложение для анализа банковских транзакций"

## Описание:
Приложение для анализа банковских транзакций с интерактивным интерфейсом. Позволяет анализировать финансовые операции, 
генерировать отчеты и использовать различные сервисы для работы с транзакциями.


## ✨ Ключевые возможности
- **📊 Визуализация данных - Главная страница с финансовой сводкой**
- **💰 Инвесткопилка - Автоматическое накопление средств через округление трат**
- **🔍 Умный поиск - Поиск транзакций по описанию, категориям, телефонным номерам**
- **📈 Аналитика - Статистика по категориям расходов за различные периоды**
- **📁 Экспорт - Автоматическое сохранение отчетов в JSON формате**


## 🚀 Установка и запуск:

# Требования
- **Python 3.9+**
- **Poetry (менеджер зависимостей)**

# Установка
1. Клонируйте репозиторий:
```
git clone git@github.com:VikaDavlyatshina/Analysis-of-bank-transactions.git
```
2. Установите зависимости с помощью Poetry:
```
poetry install
```
3. Настройка переменного окружения(для работы с API):
 Создайте файл .env в корне проекта и добавьте ваш API-ключ:
```
 API_KEY=ваш_ключ_от_API
 ```


```bash
 python -m src.main
```

## 🌐 Веб-страницы
Финансовый отчет - Генерирует детальный отчет по картам и транзакциям за указанный период.

- **Ввод даты в формате ДД.ММ.ГГГГ(ДД/ММ/ГГГГ, ДД-ММ-ГГГГ)**

- **Автоматическое сохранение отчета в формате JSON**

- **Статистика по картам, категориям, крупнейшим операциям**

## 🔧 Сервисы

# 1. 💰 Инвесткопилка
Сервис для накопления средств через округление трат:

- **Выбор месяца для анализа**
- **Установка лимита для накопления(10, 50 или 100 рублей**
- **Расчет суммы для накопления**

# 2. 🔍 Простой поиск
Поиск транзакций по ключевым словам:

- **Регистронезависимый поиск**
- **Поиск по описанию и категории**
- **Сохранение результатов поиска**

# 3. 📱 Поиск по номерам
Поиск телефонных номеров в транзакции:

- **Распознавание различных форматов номеров**
- **Подсчет найденных номеров**
- **Сохранение результатов поиска**

## 📊 Отчеты
Анализ по категориям - Детальная статистика расходов по категориям

- **Выбор категории из доступных**
- **Анализ за последние 3 месяца**
- **Подсчет сумму, количества операций, среднего чека**
- **Сохранение отчета**

## 🔧 Конфигурация

Настройка через config.py

```python
# Пути к файлам
from pathlib import Path
import logging

# Базовые пути
PROJECT_ROOT = Path(__file__).parent
DATA_DIR = PROJECT_ROOT / "data"

REPORTS_DIR = PROJECT_ROOT / "reports"

# Создаём папку reports если её нет
REPORTS_DIR.mkdir(exist_ok=True)



# Настройки логирования

# Стандартный формат логов
LOG_FORMAT = "%(asctime)s - %(name)s - %(levelname)s - %(message)s"


# ---------- Универсальная функция ----------
def create_logger(name: str, log_file: Path) -> logging.Logger:
    """Создаёт и настраивает логгер по имени и пути к файлу."""
    logger = logging.getLogger(name)
    logger.setLevel(logging.DEBUG)

    handler = logging.FileHandler(log_file, mode="w", encoding="utf-8")
    handler.setFormatter(logging.Formatter(LOG_FORMAT))

    logger.handlers.clear()
    logger.addHandler(handler)
    return logger


```
